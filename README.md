# EmployeeHub – IT Employee Management Dashboard

## About the Project
Developed a responsive IT Employee Management Dashboard (`EmployeeHub`) designed to streamline workplace operations, task tracking, leave management, and team collaboration. The application provides employees and teams with centralized access to company policies, performance reviews, market analysis insights, news updates, and an interactive enquiry portal.

🔗 **Live Demo:** (https://employee-management-61eef.web.app)

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Firebase Hosting

## Features
- **Responsive Dashboard Layout:** Clean, mobile-friendly navigation bar with sections for Home, Leave Management, MyTask, and Team.
- **Company Overview & Policies:** Dedicated sections highlighting Company Vision, Working Hours, Data Security guidelines (2FA & password standards), Performance Reviews, and Team Bonding.
- **Task & Deadline Tracking:** Interactive carousel/cards for monitoring upcoming team task deadlines and collaboration updates.
- **News & Events:** Centralized feed for company announcements, training programs, meetings, and team celebrations.
- **Multi-Year Market Analysis (2024–2026):** Tabbed data tables comparing Market Trends, Customer Needs, and Emerging Technologies across years.
- **Interactive Enquiry Form:** Real-time Bootstrap & JavaScript client-side form validation with custom feedback messages for First Name, Last Name, Email ID, Reason, Role, Mobile Number, and Terms agreement.

## Key Functionalities
- Interactive tabs and carousel navigation using JavaScript and Bootstrap 5 components.
- Responsive grid layout and structured data tables using CSS media queries and Bootstrap.
- Client-side form validation with instant visual feedback (`Looks good!` / error prompts).


## How to Run Locally
1. Clone the repository:
   ```bash
   git clone https://github.com
   ```
2. Open the project folder in Visual Studio Code.
3. Navigate to `public/index.html` and open it using **Live Server** to view the website in your browser.
